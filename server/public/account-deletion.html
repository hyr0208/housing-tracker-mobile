내 차례 계정 삭제

‘내 차례’ 계정을 삭제하면 서버에 저장된 신청 내역, 체크리스트, 알림 설정과 푸시 토큰이 즉시 삭제되고 카카오·Apple 로그인 연결이 해제됩니다. 삭제한 정보는 되돌릴 수 없습니다.

앱에서 삭제하기

  1. 앱 홈 화면에서 내 정보를 엽니다.
  2. 계정 삭제를 누르고 확인 창에서 다시 계정 삭제를 누릅니다.

앱 없이 삭제 요청하기

앱을 이미 삭제했다면 yyyerin.app@gmail.com으로 ‘계정 삭제 요청’을 보내주세요. 로그인한 방식(카카오/Apple)과 닉네임을 적어주시면 본인 확인 후 10일 이내에 삭제하고 결과를 알려드립니다.

삭제되는 정보

  • 카카오 회원번호·닉네임 또는 Apple 사용자 식별자·이름
  • 신청 내역(지역, 단지명, 공고명, 주택형, 예비순번과 이력)
  • 체크리스트, 앱 내 알림 기록, 푸시 알림 토큰

법령에 따라 따로 보관하는 정보는 없습니다. 자세한 내용은 개인정보 처리방침을 확인해주세요.
